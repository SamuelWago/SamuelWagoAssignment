# Git and GitHub Learning Project

Welcome to my Git and GitHub learning repository!

This project demonstrates the basic Git workflow, including creating a local repository, tracking files, making commits, connecting to GitHub, and sharing code publicly.

## Objectives

- Create a local Git repository and make first commit.
- Create a remote repository on GitHub.
- Synchronize local and remote repository (Push/Pull).
- Understand and use the basic git workflow: Add=>Commit+>Push.
- Create a professional README.md file using Markdown
- Use Github to share your work publicly

## Getting Started

### Prerequisites

- Git locally installed on your computer
- Python 3 installed (to run `Samuel.py`)
- Visual studio code (to write `Samuel.py`)

### Clone the Repository

```bash
git clone https://github.com/SamuelWago/SamuelWagoAssignment
cd SamuelWago
```


### Run the Python Program

```bash
python Samuel.py
```

Expected output:

```text
Table having 5 rows and 5 columns of data
```

## Basic Git Commands I used:

| Command | Purpose |
|---|---|
| `git init` | Initialize a repository |
| `git status` | Check file status |
| `git add .` | Stage changes |
| `git commit -m "message"` | Save a commit |
| `git log --oneline` | View commit history |
| `git push` | Upload commits to GitHub |
| `git pull` | Download and integrate remote changes |
| `git remote -v` | View remote repositories |
